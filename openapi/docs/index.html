required

required
number or null <float> (SakeAlcoholPercentage) [ 0 .. 100 ]

required
integer or null (SakeVolumeMax) >= 1

volumeRemain
required
integer or null (SakeVolumeRemain) [ 0 .. 100 ]

required
string or null (SakeRegion) <= 100 characters

産地

price
required
integer or null (SakePrice) >= 0

価格（円）

memo
required
string or null (SakeMemo) <= 500 characters

メモ

tagNames
required
Array of strings (SakeTagName) [ items <= 50 characters ]

タグ名前一覧

required
Array of strings (SakeImageKey)

表示順で指定する画像キー配列
