# エラーコード定義

このドキュメントでは、Sake Hack Backend APIで使用されるエラーコードとワーニングコードについて説明します。

## エラーコードの形式

- **E**: エラー（Error）- 処理が失敗した場合
- **W**: 警告（Warning）- 処理は成功したが注意が必要な場合

## エラーレスポンスの構造

すべてのエラーレスポンスは以下の構造に従います：

```json
{
  "error_code": "エラーコード",
  "message": "エラーメッセージ",
  "reason": "エラーの詳細な理由（オプション）"
}
```

### フィールド説明

- `error_code`: エラーコード（E0001, E0002, W0001, E9000のいずれか）
- `message`: エラーの詳細メッセージ
- `reason`: エラーの詳細な理由（null許容、オプション）

## エラーコード一覧

| エラーコード | 説明 | HTTPステータス | 発生条件 |
|------------|------|---------------|---------|
| E0001 | 認証エラー | 401 Unauthorized | 認証トークンが無効・期限切れ、または提供されていない |
| E0002 | データベース実行エラー | 500 Internal Server Error | データベース接続の失敗、SQL実行エラー、トランザクションエラー |
| W0001 | バリデーションエラー | 400 Bad Request | 必須パラメータの欠損、パラメータの型・値・形式が不正 |
| E9000 | その他エラー | 500 Internal Server Error | 上記に該当しない予期しないエラー |

## HTTPステータスコードとエラーコードの対応

| HTTPステータスコード | エラーコード | 説明 |
|---------------------|------------|------|
| 400 Bad Request | W0001 | バリデーションエラー |
| 401 Unauthorized | E0001 | 認証エラー |
| 500 Internal Server Error | E0002 | データベース実行エラー |
| 500 Internal Server Error | E9000 | その他エラー |
