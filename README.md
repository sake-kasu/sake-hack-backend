# PR Documentation Previews

This branch contains PR-specific documentation previews.

Each PR has its own directory: `/pr-<number>/`

## Structure

```
/
├── pr-1/           # PR #1 のドキュメント
│   └── index.html
├── pr-2/           # PR #2 のドキュメント
│   └── index.html
└── README.md       # このファイル
```

## Access

PR previews are available at:
`https://<owner>.github.io/<repo>/pr-<number>/`
