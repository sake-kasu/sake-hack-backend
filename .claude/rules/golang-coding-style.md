# Goコーディング規約

> CLAUDE.md の禁止事項と合わせて必ず遵守すること。

## フォーマット

- **gofmt** と **goimports** は必須 — スタイルの議論は不要
- `.go` ファイル編集後にフックで自動適用される
- 手動実行: `make lint` (gofmt + golangci-lint)

## 設計原則

- インターフェースを受け取り、構造体を返す
- インターフェースは小さく保つ(1-3メソッド)
- インターフェースは使用する側(Consumer)で定義する

## エラーハンドリング

エラーは必ずコンテキスト付きでラップする:

```go
if err != nil {
    return fmt.Errorf("ユーザーの作成に失敗: %w", err)
}
```

- `errors.Is` / `errors.As` でエラーを判定する
- `_` でのエラー無視は禁止(テスト以外)
- `panic` は回復不能なエラーのみに限定

## 言語ルール(必須)

- **全コメント・ログ・エラーメッセージは日本語**で記載すること
- **全角括弧(())の使用禁止** — 半角括弧()を使用
- **`#nosec` による gosec 警告抑制禁止**
- **`//nolint` コメントの追加禁止**(明示的な承認なし)

## ファイル・関数サイズ

- ファイルサイズ上限: **800行**
- 関数サイズ上限: **50行**
- ネスト深度上限: **4レベル**

## 命名規則

- パッケージ名: 短い小文字、アンダースコアなし
- エクスポート関数: パスカルケース、動詞始まり
- 非エクスポート: キャメルケース

## 参照

- スキル: `golang-patterns` — 包括的なGoイディオムとパターン
- Lint実行: `make lint`
